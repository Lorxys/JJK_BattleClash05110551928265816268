# Sons du jeu

Dépose ici les fichiers audio en **MP3** (format lu partout : Android, iPhone, PC),
avec **exactement** ces noms. Chaque fichier présent remplace le son synthétisé
correspondant ; s'il manque, le jeu garde son bruitage généré par le code.

## Musiques (jouées en boucle)

| Fichier | Quand |
|---|---|
| `musique.mp3` | Musique principale pendant la partie |
| `musique_territoire.mp3` | Pendant l'extension du territoire |
